# Gestion de Usuarios SQL


La administración de usuarios dentro de una base de datos es uno de los aspectos más importantes en la seguridad informática y en la correcta organización de la información.

No todos los usuarios que acceden a una base de datos deben tener los mismos privilegios. Dependiendo del cargo, función o responsabilidad dentro de una organización, cada persona debe contar únicamente con los permisos necesarios para desarrollar su trabajo.

MySQL permite crear usuarios independientes y asignar privilegios específicos sobre una base de datos, tablas o acciones determinadas, lo cual ayuda a proteger la información y reducir errores humanos.

En este proyecto se desarrolló un ejercicio práctico enfocado en la creación de usuarios con distintos niveles de acceso, específicamente el rol correspondiente al **usuario con permisos de modificación**.

El cual tenga permisos para administrar datos dentro de la base de datos, pudiendo realizar acciones como:

Consultar información
Insertar registros nuevos
Modificar registros existentes
Eliminar datos innecesarios

Sin permitirle acciones administrativas como:

Crear tablas nuevas
Eliminar tablas existentes
Modificar la estructura de la base de datos
Administrar otros usuarios
